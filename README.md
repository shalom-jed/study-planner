# Study Planner

A Java application for optimizing academic task scheduling using data structures 
and algorithms.

## 📚 Coursework Project

PDSA (Problem Solving Using Data Structures and Algorithms) module at NIBM.

## ✨ Features

- Intelligent task scheduling
- DAG (Directed Acyclic Graph) for dependencies
- Max-Heap priority queue
- N-ary tree for subject hierarchies
- Kahn's algorithm for topological sorting

## 💻 Tech Stack

Java • Data Structures • Algorithms

## 📂 Structure

Core data structures used:
- DAG & Kahn's Algorithm
- Max-Heap Priority Queue
- N-ary Trees
- Java Swing (GUI)
